Install ktfigure

Get ready to create.

Download the desktop app for your computer. Python and Git are not needed.

Download from GitHub Releases ↗

Choose the matching archive, extract it, and keep the extracted files together:

  • Windows 64-bit: ktfigure-windows-x64.zip — open ktfigure/ktfigure.exe.
  • macOS Apple silicon: ktfigure-macos-arm64.zip — open ktfigure.app.
  • macOS Intel: ktfigure-macos-x64.zip — open ktfigure.app.
  • Linux x86-64: ktfigure-linux-x64.tar.gz — open ktfigure/ktfigure on a graphical desktop.
These builds are unsigned, so Windows or macOS may warn before opening them. On macOS, if blocked, verify the download and use System Settings → Privacy & Security → Open Anyway. On Linux, allow the file to run as a program if needed, or run ./ktfigure/ktfigure in a terminal.

Alternatively, to install from source you need Python 3.10 or later, Git and Tkinter:

git clone https://github.com/tuonglab/ktfigure.git
cd ktfigure
pip install .
Need Tkinter? On Ubuntu/Debian, run sudo apt-get install python3-tk; on Fedora, run sudo dnf install python3-tkinter. On macOS and Windows, Tkinter is included with the standard python.org installer.

Quick Start

Make your first plot.

Open the downloaded app as described above. If you installed from source, launch it with ktfigure in a terminal.

  1. Click Plot, then drag a rectangle on the artboard to create a plot region.
  2. In the Data tab, browse for a CSV or TSV. Try example_data.csv or use the copy in the cloned repository.
  3. Choose scatter, map temperature to X, sales to Y and season to Hue, then click Apply.
  4. Select the plot to adjust its properties, then choose PDF, SVG or PNG to export. Review the export notes before publishing.
